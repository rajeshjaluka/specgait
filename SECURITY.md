# Security Policy

## Supported Versions
We actively release security patches and updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability, report it using one of the following methods:

1. **GitHub Private Vulnerability Reporting (Preferred):** Go to the repository's **Security** tab $\rightarrow$ **Advisories** $\rightarrow$ click **"Report a vulnerability"**.
2. **Email:** Send details directly to **opensource@agileclevel.com**.

### What to Include
To help us triage and resolve the issue quickly, please include:
- A description of the issue and potential impact
- Steps to reproduce or proof-of-concept code/requests
- Any potential mitigations you have identified

### Response Timeline
- **Initial Response:** Within 48 hours to confirm receipt.
- **Status Update / Assessment:** Within 7 days.
- We request that you maintain confidentiality until we have had reasonable time to release a patch.
